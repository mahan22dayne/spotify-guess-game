# حدس آهنگ از روی پلی‌لیست اسپاتیفای یا دیزر

بازی‌ای شبیه چیزی که استریمرهایی مثل Ohnepixel اجرا می‌کنن: یه پلی‌لیست بده، از هر آهنگ یه تکه‌ی کوچیک (۰.۵ ثانیه → ۱ → ۳ → ۵) پخش می‌شه و باید حدس بزنی.

## راه‌اندازی (بدون نیاز به هیچ کلید یا پریمیوم)

```bash
npm install
npm start
```
سرور روی `http://localhost:3000` بالا میاد. همین! نیازی به فایل `.env` یا کلید اسپاتیفای نیست.

## چطور کار می‌کنه

از فوریه‌ی ۲۰۲۶ اسپاتیفای استفاده از API رسمیش رو منوط به داشتن اشتراک پریمیوم روی اکانتِ صاحبِ اپ کرده، پس این پروژه به‌صورت پیش‌فرض از دو منبع دیگه استفاده می‌کنه:

- **لینک اسپاتیفای** (`open.spotify.com/playlist/...`): سرور صفحه‌ی عمومی پلی‌لیست رو می‌خونه (مثل یه مرورگر) و از دیتای تعبیه‌شده‌ی توی خودِ صفحه، اسم آهنگ‌ها و خواننده‌ها رو استخراج می‌کنه. این یه روش **غیررسمیه** — مستند نیست و ممکنه یه روز اسپاتیفای ساختار صفحه رو عوض کنه و از کار بیفته، یا برای پلی‌لیست‌های خیلی بزرگ فقط بخشی از آهنگ‌ها رو بگیره.
- **لینک دیزر** (`deezer.com/.../playlist/...`): مستقیم از API رسمی و پایدار Deezer (بدون نیاز به کلید) کل لیست آهنگ‌ها به همراه preview صوتی گرفته می‌شه — این روش قابل‌اعتمادتره.

در هر دو حالت، برای آهنگ‌هایی که preview صوتی مستقیم ندارن (مثلاً از اسپاتیفای، چون preview خودشو استخراج نمی‌کنیم)، سرور خودکار اسم آهنگ + خواننده رو تو **Deezer جستجو** می‌کنه و preview 30 ثانیه‌ای معادلش رو پیدا می‌کنه.

اگه بعداً خواستی، همچنان می‌تونی با ساختن `.env` (از روی `.env.example`) و گذاشتن `SPOTIFY_CLIENT_ID`/`SPOTIFY_CLIENT_SECRET` مسیر رسمی اسپاتیفای رو هم فعال کنی؛ اگه اون کلیدها باشن و اکانتش پریمیوم داشته باشه، سرور اول همون مسیر رسمی رو امتحان می‌کنه و اگه جواب نداد خودکار می‌ره سراغ روش scrape.

## چطور بازی می‌شه

- هر راند از پلی‌لیست شافل‌شده گرفته می‌شه (حداکثر ۱۲ راند در هر بازی).
- دکمه‌ی پخش، آهنگ رو از ثانیه‌ی صفر تا مرحله‌ی فعلی (۰.۵/۱/۳/۵ ثانیه) پخش می‌کنه.
- اینپوت حدس، از بین اسم آهنگ‌های پلی‌لیست autocomplete پیشنهاد می‌ده.
- هر حدس اشتباه یه مرحله جلو می‌بره؛ اگه تو مرحله‌ی ۵ ثانیه هم اشتباه بود یا "تسلیم" رو زدی، جواب درست نشون داده می‌شه.
- امتیاز هر راند بر اساس این‌که تو کدوم مرحله درست حدس زدی محاسبه می‌شه (۱۰۰/۷۵/۵۰/۲۵).

## محدودیت‌ها که خوبه بدونی
- پلی‌لیست باید **عمومی (public)** باشه.
- روش scrape اسپاتیفای رسمی نیست؛ اگه یه روز جواب نداد، همون لینک رو با یه پلی‌لیست معادل از Deezer امتحان کن (مطمئن‌تره)، یا صبر کن و دوباره امتحان کن.
- برای دیپلوی (مثلاً Render/Railway/Vercel)، چیز خاصی لازم نیست تنظیم کنی مگر این‌که بخوای مسیر رسمی اسپاتیفای رو هم فعال کنی.
